# Tabroom Theme

A lightweight Chrome extension that applies a cleaner, brighter UI to Tabroom pages.

## Features

- Light-first styling with readable spacing and contrast
- Optional dark mode
- Custom accent color
- Compact view toggle

## Load the extension

1. Open `chrome://extensions` in Chrome.
2. Turn on Developer mode.
3. Click "Load unpacked".
4. Select this folder.

## Files

- `manifest.json` - Chrome extension manifest
- `content.js` - applies theme preferences to Tabroom pages
- `content.css` - visual styling and layout polish
- `popup.html` / `popup.js` / `popup.css` - extension popup controls
